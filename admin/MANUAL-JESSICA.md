no# 🚀 CÓMO USAR EL PANEL ADMIN DE TOCCA

### 1️⃣ ABRIR EL ADMIN

**HAZ DOBLE CLICK EN:**
```
📁 tocca-producción/admin/ABRIR-ADMIN.bat
```

Esto abrirá:
- Una ventana negra (servidor) - **NO LA CIERRES**
- Tu navegador con el admin

---

## 🎨 EDITAR TU PÁGINA

### OPCIÓN A: Cargar Página Existente

1. **Click en "Cargar Página"** (botón arriba a la derecha)
2. **Selecciona tu página**:
   - 🏠 Página Principal (index.html)
   - ✨ Signature Journey
   - 🎨 Bespoke Journey
   - Etc.

3. **Espera 2 segundos** - Los bloques aparecerán en el centro

4. **Edita bloques**:
   - Click en cualquier bloque del centro
   - En el panel derecho cambia:
     - ✏️ Textos
     - 🎨 Colores
     - 📏 Tamaños
     - 🖼️ Imágenes
   - Los cambios se ven EN TIEMPO REAL

5. **Guarda**:
   - Click "Exportar"
   - Se descarga el HTML editado
   - **REEMPLAZA** el archivo original en tu carpeta

### OPCIÓN B: Crear desde Cero

1. **Arrastra bloques** desde el sidebar izquierdo:
   - 📝 Texto (títulos, párrafos)
   - 🖼️ Imagen
   - 🔘 Botón
   - 📦 Sección

2. **Edita** igual que opción A

3. **Exporta** cuando termines

## 🆘 ¿PROBLEMAS?

**El botón "Cargar Página" no funciona:**
- Verifica que la ventana negra (servidor) esté abierta
- Refresca el navegador (F5)

**No veo mis cambios en la página real:**
- Descarga con "Exportar"
- Ve a tu carpeta `tocca-producción/`
- Reemplaza el archivo HTML original con el descargado
- Refresca tu página web
